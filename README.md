A small Python program that writes a one-sentence pitch of the worst, most useless app imaginable — SockMatch, an AI that texts your dryer about your missing sock — to /output/entry.txt. The line is fixed and deterministic — the same 213-character line every run.

## Run it

```sh
python3 main.py
```
